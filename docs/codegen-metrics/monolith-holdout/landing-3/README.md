# Golden Crumb Bakery — Landing Page

A polished, fully responsive landing page for a neighborhood artisan bakery built with React + Vite.

## Features

- **Hero Section** — Full-bleed warm gradient hero with bakery name, tagline, and CTA buttons
- **Sticky Navigation** — Transparent nav that becomes opaque on scroll
- **Menu Teaser** — 6 featured items (breads, pastries, cakes & tarts) in a responsive grid
- **Category Filter Tabs** — Filter menu items by category with animated state
- **Interactive Cards** — Hover effects and "Add to Order" button with confirmation state
- **Footer** — Hours, address, contact info, and social links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Tech Stack

- React 18
- Vite 5
- Pure CSS (no UI libraries)
- No external image dependencies — emoji + CSS gradients used throughout
