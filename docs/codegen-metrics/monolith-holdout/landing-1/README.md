# Clay & Fire Pottery Studio

A polished landing page for a community pottery studio, built with React + Vite.

## Features

- **Sticky Navbar** — smooth-scrolls to each section; collapses to a hamburger menu on mobile
- **Hero Section** — headline, subtext, dual CTAs, trust badges, and a decorative pottery illustration
- **Pricing Section** — three interactive cards (Drop-In, Monthly, Private Workshop) with hover/select states and a booking confirmation flash
- **About Section** — studio story, stats grid, and an accent card
- **Footer** — contact info, hours, and navigation links

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Customisation

All copy, pricing, and studio details live in **`src/data/studioData.js`** — edit that file to update content without touching component logic.

## Build

```bash
npm run build
npm run preview
```
